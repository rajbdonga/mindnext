1-Min Setup Guide
Connect your free Google Apps Script Web App to dispatch emails directly from business.mindnext@gmail.com.

Gmail Direct Dispatch Setup (1 Minute)

Browser security restrictions ki vajah se koi bhi static website directly smtp.gmail.com se raw connect nahi kar sakti. Isliye Google ne Google Apps Script diya hai jisse aapke Gmail (business.mindnext@gmail.com) se emails 100% direct send hote hain:

Steps to Setup (Sirf 1 baar karna hai):
  1. Naye tab me script.google.com open karein (business.mindnext@gmail.com se login karein).
  2. New Project par click karein.
  3. Jo default code likha hai usko hata kar neeche ka code paste karein:
function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  GmailApp.sendEmail(d.to, d.subject, d.body, {
    name: d.senderName || "MINDNEXT Technologies",
    htmlBody: d.body.replace(/\n/g, "<br>")
  });
  return ContentService.createTextOutput("SUCCESS");
}
  1. Upar Deploy → New deployment click karein.
  2. Select type me Web app choose karein.
  3. Execute as: Me (business.mindnext@gmail.com) aur Who has access: Anyone karke Deploy karein.
  4. Jo Web app URL mile (jaise https://script.google.com/macros/s/.../exec), use copy karke Account me paste karein!
